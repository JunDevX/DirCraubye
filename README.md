# DirCraubye

**DirCrabue** — это консольная утилита на C# (.NET 8), которая позволяет мгновенно воссоздавать полную структуру папок и файлов проекта из обычного текстового представления дерева (ASCII-дерева), скопированного из Документации, Notion, ChatGPT или GitHub.

## Возможности

* **ASCII Art** при запуске приложения.
* **Интерактивный выбор папки** через стандартный проводник Windows.
* **Автоматический парсинг ASCII-деревьев** (поддерживает символы `├──`, `└──`, `│` и обычные отступы).
* **Авто-очистка ввода** от непечатаемых символов и нулевых байт (`\0`), возникающих при вставке из буфера обмена.
* **Автоматическое разделение**: файлы (с расширениями) создаются пустыми файлами, а категории — папками.

## Требования к сборке

Для сборки из исходников вам понадобится:

* [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) или новее.

## Сборка и Запуск

### 1. Запуск в режиме разработки (Кроссплатформенно)

```bash
dotnet run
```

### 2. Сборка бинарных файлов (Publish)

Вы можете собрать проект в виде **одного самостоятельного файла (`SingleFile`)**, которому для работы не потребуется предварительно установленный .NET SDK на целевом компьютере.

#### Для Windows (x64)

```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

> Готовый `.exe` файл будет находиться в:
> `bin/Release/net8.0-windows/win-x64/publish/DirCreator.exe`

#### Для Linux (x64)

> *Примечание:* Для работы диалога выбора папки на Linux через Windows Forms требуется поддержка Wine, либо запустите CLI-версию (выбор пути текстом).

Для сборки автономного бинарника под Linux выполните:

```bash
dotnet publish -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true
```

> Готовый исполняемый файл будет находиться в:
> `bin/Release/net8.0-windows/linux-x64/publish/DirCreator`

Запуск на Linux:

```bash
chmod +x ./DirCreator
./DirCreator
```

## Пример использования

1. Запустите приложение.
2. Нажмите `1` и выберите целевую директорию вашего будущего проекта.
3. Скопируйте структуру текстового дерева, например:

```text
zapl-git-cloud/
├── package.json
├── server.js
├── public/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── main.js
└── views/
    ├── layout.ejs
    ├── home.ejs
    ├── git-home.ejs
    ├── git-profile.ejs
    └── git-repo.ejs
```

4. Вставьте текст в консоль.
5. Для завершения ввода нажмите **Enter**, затем **Ctrl + Z** (на Windows) или **Ctrl + D** (на Linux) и снова **Enter**.
6. Готово! Все папки и файлы созданы.

## Решение проблем

* **Ошибка `NETSDK1136`**: Убедитесь, что в файле `.csproj` указана целевая платформа `<TargetFramework>net8.0-windows</TargetFramework>`.
* **Символы `^Z` при вводе**: Это стандартный символ `EOF` (End Of File) для терминалов Windows, подтверждающий завершение чтения многострочного ввода.
